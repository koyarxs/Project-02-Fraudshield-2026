# 🛡️ FraudShield

### Sistema de apoyo para la clasificación de riesgo en transacciones digitales

FraudShield es un MVP orientado al procesamiento y análisis de registros transaccionales digitales, permitiendo aplicar reglas de detección y clasificar automáticamente las transacciones según su nivel de riesgo.

---

## 🚀 Funcionalidades

- 🔐 Autenticación y gestión de usuarios mediante JWT
- 📁 Carga y validación de archivos transaccionales
- ⚙️ Procesamiento de transacciones por lotes
- 🛡️ Motor de reglas de riesgo R1–R5
- 📊 Clasificación automática de niveles de riesgo
- 📈 Dashboard y métricas
- 🕒 Historial y trazabilidad
- 🔎 Gestión de casos y auditoría
- 📋 Listas de control
- 📄 Reportes y exportación de resultados
